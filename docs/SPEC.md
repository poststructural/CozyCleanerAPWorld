# Cozy Cleaner AP: shared contract (world, client, plugin)

Plan: `docs/plans/2026-11-02-cozy-cleaner-ap.md`. Level table: `world/cozy_cleaner/data/levels.json`
(generated by `tools/gen_world_data.py`; fields `id, scene, build_index, kind, name, verb, total,
stage1, stage2, tools`). `kind` is `tutorial | house | recycling | garden | fridge | repair | lawn`.
Level 1 is the tutorial; level 36 is the last level; mini-games are 5, 11, 17, 23, 30.

Game name: **`Cozy Cleaner`**. APWorld package: `cozy_cleaner`. Base ID: `0xC0C1_0000` (locations
and items numbered from there, stable order = the order defined below).

## Location names (exact strings; the plugin sends these through the bridge)

For each level `L` (with `N = L.name`, e.g. `Level 9`, `Tutorial`, `Level 5 Recycling`):

| Location | When | Option |
|---|---|---|
| `{N} - Complete` | level finished | always |
| `{N} - Stage 1 Done`, `{N} - Stage 2 Done` | house/tutorial `CleaningProgress` stage events | `stagesanity` |
| `{N} - {verb} #{k}` for k = 1..total | k-th progress unit in one playthrough | `cleansanity` (houses + tutorial) / `minigamesanity` (mini-games) |
| `Shop - {Tool} Upgrade {s}` for s in 1,2 | buying the s-th upgrade of a tool in the shop | `shopsanity` |
| `Achievement - {Title}` | `AchievementManager.Unlock(id)` | `achievementsanity` |

- `cleansanity`: `off`, `milestones` (only k = ceil(total*p) for p in 25/50/75/100%), `every_object` (default).
- `minigamesanity`: `off`, `milestones`, `every_unit` (default). Lawn under `every_unit` uses
  groups: k in 10, 20, ... (and `total` itself) unless `lawn_every_cut: true`, which makes every cut a check.
  The plugin sends `#k` for every k reached; the client ignores names not in the seed, so the
  plugin never needs to know which subset is active.
- Tools (`{Tool}`): `Hand`, `Dustpan`, `Cloth`, `Mop`, `Watering Can`, `Vacuum`
  (game enum `CleaningToolType`: Hand=1, Dustpan=2, Cloth=3, Mop=4, Watering_Can=5, supurge=6 is Vacuum).
- Achievement titles: id `ACH_<X>_Title` -> title is `<X>` split on capitals: `First Steps`, `Gentle Touch`,
  `Curious Hands`, `Guiding Paw`, `First Upgrade`, `Perfect Tool`, `Well Equipped Cleaner`,
  `Novice Cleaner`, `Master Cleaner`, `Clean City`, `Jack Of All Trades`, `Trash Hunter`,
  `Spotless Corners`, `Sparkling Floors`, `Flower Friend`, `Recycling Master`, `Repair Master`,
  `Organized Fridge`, `Gardener`, `Freshly Mowed`.
- Safety net: when a level completes, the plugin also sends every `{N} - {verb} #k` and both stage
  checks for that level, so a static count that is too high can never strand a check.

## Items

| Item | Count | Class |
|---|---|---|
| `{N} Key` (one per level except the tutorial, which is open) | 35 | progression |
| `Cloth`, `Watering Can` | 1 each, always | progression |
| `Dustpan`, `Mop`, `Vacuum` | 1 each when `toolsanity: true` (else owned from start) | progression |
| `Progressive {Tool} Upgrade` for all 6 tools | 2 each when `shopsanity: true` | useful |
| `Money Bundle` (filler; value = 50 x `money_multiplier`) | fill the rest | filler |

## Logic

- Region per level, reached from Menu with `{N} Key` (tutorial free) and the level's `tools`
  (Dustpan/Mop/Vacuum only count when `toolsanity`; otherwise only Cloth / Watering Can are ever required).
  The tutorial needs no tools in any mode (the tutorial forces its own tools).
- Shop upgrade s=1 needs 3 levels reachable, s=2 needs 8 (money).
- Achievements: Novice = 10 levels, Master = 20, Clean City = level 36, Jack Of All Trades = all 5
  mini-games, Recycling/Repair/Organized Fridge/Gardener/Freshly Mowed = that mini-game,
  First Steps / Guiding Paw = tutorial, Gentle Touch / Curious Hands = free (main menu),
  Trash Hunter / Spotless Corners / Sparkling Floors = 6 house levels, Flower Friend = Watering Can + 3
  levels whose tools include Watering Can. First Upgrade / Perfect Tool / Well Equipped Cleaner: with
  shopsanity, 1 / 2 of one tool / all 12 `Progressive ... Upgrade` items; without, same as shop s=1/s=2/s=2.
- Goal (`goal`): `final_level` (default, `Level 36 - Complete`) or `levels_completed` with
  `levels_needed` (default 25).

## Slot data (client writes it into `slot.json`)

`{"goal": "final_level"|"levels_completed", "levels_needed": int, "toolsanity": bool,
"shopsanity": bool, "money_multiplier": int, "death_link": false, "seed": str, "slot": int,
"player": str, "levels": <levels.json contents>}`

## Bridge (folder `~/CozyCleanerAP/<seed>_<slot>/`, both OSes; `~` = user home)

The client writes `~/CozyCleanerAP/current.txt` holding the active folder name, so the plugin finds it.

- `slot.json`  client -> plugin, rewritten on connect.
- `items.jsonl` client -> plugin, append-only: `{"index": n, "item": "<name>", "player": "<sender>"}`.
- `checks.jsonl` plugin -> client, append-only: `{"location": "<name>"}` or `{"type": "goal"}`.
- `checked.json` client -> plugin, rewritten: list of location names already checked on the server
  (lets the plugin skip resends and run achievement `IsUnlocked`).
- `status.json` plugin -> client: `{"level": id, "scene": name, "connected_seed": str}` (display only).
- Plugin keeps its own `plugin_state.json` (applied item index, per-level best counts) in the same folder.
- Game save isolation: the plugin redirects `SaveManager` paths to `<bridge>/save/` so AP runs do
  not touch the normal save.
